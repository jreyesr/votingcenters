# Contributing

This project adheres to the [SciActive Human Contribution Policy 2-NE](HUMAN-CONTRIBUTION-POLICY-2-NE.md), both in the
descriptive sense (as regardsthe contributions already made and to be made by me, @jreyesr) and normatively (as regards
the contributions of anyone else). This applies to all forms of interaction with the project, including but not limited
to code and communications (e.g. issues).
